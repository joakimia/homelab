# Homelab Job chart

**Status: scaffold.** This directory reserves a place for a base chart for a one-off Job (for example a migration or a backup restore), like [`homelab-cron-job`](../homelab-cron-job/README.md) without the schedule.

The chart metadata, values, templates, and install script are not implemented yet. Do not include it in the `homelab` chart until it has been completed and validated.
